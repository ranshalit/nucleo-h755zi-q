# Direction and stop keyword fixtures

One-second 16 kHz mono clips from the **testing** split of Google
[Speech Commands v0.02](https://storage.googleapis.com/download.tensorflow.org/data/speech_commands_v0.02.tar.gz)
(CC BY 4.0, Pete Warden, "Speech Commands: A Dataset for Limited-Vocabulary
Speech Recognition", arXiv:1804.03209). They were not used for training.
